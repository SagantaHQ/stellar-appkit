Wallets

Every wallet, one interface.

New wallets are one file, not a redesign — the adapter interface is aligned with SEP-43, the standard the ecosystem is converging on.

Freighter extension + mobile Albedo no install xBull extension + webapp Ledger WebHID / WebUSB WalletConnect in progress
What's built in

Past "connect a wallet."

Nothing hidden in a popup

Every operation in a transaction is decoded and shown before the wallet's own prompt — account merges and signer changes are always flagged.

Soroban, one call

Build, simulate, prepare, sign, submit, and poll a contract invocation with a single invoke() — plus a preview that runs real simulation first.

Multiple wallets, one session

Connect Freighter and Ledger at once. Switch which is active without disconnecting either.

Looks like your app

Every color, radius, and font is a CSS custom property. Restyle it from your own stylesheet — no JS theming API required.

Recovers from a wrong network

A typed NetworkMismatchError instead of a dead end, with an optional mode that waits for the user to switch and continues automatically.

Only ships what you use

Every connector is independently tree-shakeable. Import one wallet or five — nothing else rides along.

Quick start

Working in about ten lines.

import {
  StellarAppKit,
  createFreighterConnector,
  createAlbedoConnector,
} from '@saganta/stellar-appkit';
import '@saganta/stellar-appkit/ui-web'; // registers <saganta-appkit-modal>

const appkit = new StellarAppKit({
  network: 'PUBLIC',
  connectors: [createFreighterConnector(), createAlbedoConnector()],
  appMetadata: { name: 'My App', domain: 'app.example.com', uri: 'https://app.example.com' },
});

const modal = document.querySelector('saganta-appkit-modal');
modal.client = appkit;
connectButton.addEventListener('click', () => modal.open());
