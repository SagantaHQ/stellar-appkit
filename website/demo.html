stellar appkit · demo

Connect any Stellar wallet.

Everything on this page runs the real, built package — no bundler, no framework, no mocked states. Freighter, Albedo, xBull, and Ledger are all wired up below.

Theme & presentation

Every control below just sets an attribute or a CSS custom property on the element — nothing here is a special demo mode.

Custom-branded instance

A second instance with --sak-color-accent overridden from this page's own stylesheet — proves theming crosses the shadow-DOM boundary without any JS API.

Inline mode

No overlay — renders directly in the page flow, for embedded checkout-style placements.

Sign-In With Stellar

Connect a wallet above first, then sign a SIWS message — the exact envelope a backend would verify with @saganta/stellar-appkit-siws-verify.


  


  

    
Transaction preview

    
Builds an unsigned self-payment and calls client.signTransaction() — since the modal is attached, it decodes the operation and shows an Approve/Reject screen before the wallet's own signature prompt ever appears, instead of passing raw XDR straight through.
